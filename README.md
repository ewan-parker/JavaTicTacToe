## Java Tic-Tac-Toe

A simple **console-based Tic Tac Toe game** written in Java.  
Two players take turns to place `X` and `O` on a 3x3 grid.

[See example output](exampleOutput.txt)


**Notes:**  
  - Player 1 is assigned `X`.  
  - Player 2 is assigned `O`.
  - Player 1 always begins the game.
  - Input is read from the console. 
  - Players enter the row and column numbers (1-3) to place their mark.  
  - The game checks for invalid input and spots that are already taken.  
  - The game automatically detects a win or a draw.  
  - A draw occurs when all spots are filled and no player has won.
